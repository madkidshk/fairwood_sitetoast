# SITE 多士大對決 · Fairwood 2026 STEM Campaign

Battle microsite for Fairwood × 全港網民 SITE 多士大對決 (2026.06.02 → 06.23).
Open `wireframe-visual-v2.html` (or `index.html`) — static HTML/CSS/JS, no build.

## 結構
- `wireframe-visual-v2.html` · 主 site (also as `index.html`)
- `styles.css` · brand design tokens
- `rules.txt` · 比賽規則 (open via 詳細規則 overlay)
- `assets/` · mascot + logo + reference photos
- `previews/` · 10 mock site iframe sources (5 鴨蛋派 + 5 花生派)
- `team-duck.html` / `team-peanut.html` · 2 demo site samples

## Deploy
任何靜態 host 都得 — Netlify / Cloudflare Pages / Vercel / GitHub Pages.
